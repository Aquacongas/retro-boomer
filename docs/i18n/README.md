# Historical upstream translations

The existing translated documents in this directory are preserved historical
upstream references. They are not current Retro Boomer build, wallet or release
instructions. Their original names, paths, measurements and protocol descriptions
may reflect an earlier chain. No current deployment should copy commands from
these archived translations without source verification.

Current project documentation and maintenance changes are written in English.
Use the [current project overview](../../README.md),
[current build instructions](../../RETRO_BOOMER_BUILD_INSTRUCTIONS.md) and
[release procedure](../../.github/RELEASING.md).
