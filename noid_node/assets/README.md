# Archived original-chain artifact

`mainnet-retirement.origin` belongs to the original Parano1d chain. Retro Boomer V1 does not embed, load or require it. It remains here as original source material, not as an acceptance artifact for the new blockchain.

Retro Boomer V1 uses its independent genesis and a freshly derived three-class bank. See the root README and `bench_prover/src/bin/retro_boomer_v1_pack.rs` for qualification and generation.
